# Портфолио Анастасии Велюги

Лендинг-портфолио для услуг по оформлению презентаций, учебных материалов и контента для социальных сетей.

## Макет

Исходный дизайн находится в Figma:

https://www.figma.com/design/Lo2FVw5QV3ol18B0sLAMJI/

Для реализации использовать макет `Portfolio — Simple layout / 1440` как основную десктопную версию. В файле также есть отдельные версии для планшета и телефона.

## Ключевое правило ширины и фона

Композиция лендинга не должна растягиваться вместе с широким экраном. Контент остаётся в центральном контейнере с максимальной шириной `1440px` и сохраняет существующие отступы и выравнивание.

Фон страницы при этом заполняет всю ширину и высоту окна браузера, включая свободные поля слева и справа от контейнера.

```css
html,
body {
  min-width: 320px;
  min-height: 100%;
  margin: 0;
  background: var(--color-bg);
}

.page {
  min-height: 100vh;
  background: var(--color-bg);
}

.page__content {
  width: min(100%, 1440px);
  margin-inline: auto;
}
```

На экранах уже `1440px` контейнер занимает доступную ширину; внутренние отступы и перестроение секций задаются медиазапросами. На экранах шире `1440px` элементы не увеличиваются и не смещаются — меняется только объём фонового поля вокруг них.

## Стек

Подойдёт любой современный фронтенд-стек. Рекомендуемый минимум: HTML, CSS и JavaScript. Интерактивные элементы можно реализовать без библиотек.
