# Аудит Figma перед переносом

Дата проверки: 4 октября 2026.

## Что готово

- Есть версии лендинга для десктопа, планшета и телефона.
- Основной лендинг, его секции и карточки собраны на Auto Layout.
- У карточек кейсов настроено открытие трёх прокручиваемых viewer-экранов:
  - презентация «Чистый город»;
  - рабочие листы `Concert Ready`;
  - карточки для соцсетей.
- Пункты меню ведут к разделам «Услуги», «Работы», «Обо мне» и «Контакты».
- `Telegram` ведёт на `https://t.me/nastivel`.

## Что важно учесть в коде

1. Фон должен заполнять весь viewport, но контент остаётся в центральном контейнере с максимальной шириной 1440 px.
2. В Figma основной фрейм сейчас имеет ширину 1339 px, хотя назван `/ 1440`; в CSS следует использовать `max-width: 1440px`.
3. Адрес `velnast@gmail.com` нужно вернуть в видимый блок контактов. По клику он копируется в буфер; toast «Почта скопирована» закрывается через 500 мс.
4. На телефоне карточки и двухколоночные блоки переходят в одну колонку. Ничего не скрывать и не обрезать по краям.
5. Figma-прототип не заменяет реализацию: скролл оверлеев, закрытие по фону, копирование и открытие Telegram нужно повторить в браузере.
