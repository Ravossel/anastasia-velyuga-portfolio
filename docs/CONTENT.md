# Контент и интерактивы

## Контакты

- Email: `velnast@gmail.com`.
  - По клику адрес копируется в буфер обмена.
  - Показывается центрированное уведомление «Почта скопирована».
  - Уведомление исчезает автоматически через `500ms`.
- Telegram: ссылка `https://t.me/nastivel`.
  - Открывает пользователя `@nastivel` в новой вкладке или приложении Telegram.

> Проверка Figma 04.10.2026: в видимой версии блока контактов остался только текст `Telegram`; текстовый слой с email отсутствует. Адрес и его поведение выше остаются согласованным требованием и должны быть восстановлены при разработке.

Пример логики:

```js
async function copyEmail() {
  await navigator.clipboard.writeText('velnast@gmail.com');
  showToast('Почта скопирована', { duration: 500 });
}
```

## Навигация

Каждый пункт шапки плавно прокручивает страницу к соответствующей секции. Для доступности у ссылок должны быть настоящие `href`-якоря: `#services`, `#projects`, `#about`, `#contacts`.

## Кейсы

Карточки открывают полноэкранный оверлей с содержимым:

- презентация «Чистый город» — 8 слайдов;
- рабочие листы `Concert Ready` — теория и практика;
- карточки для социальных сетей — 2 карточки.

Оверлей должен прокручиваться от первого до последнего материала. По клику на затемнённый фон он закрывается, при этом позиция пользователя на лендинге сохраняется.
