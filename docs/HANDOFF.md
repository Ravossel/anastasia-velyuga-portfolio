# Передача макета в разработку

## Адаптивность

В Figma подготовлены отдельные композиции для трёх форматов:

| Формат | Макет | Ширина |
| --- | --- | --- |
| Десктоп | `Portfolio — Simple layout / 1440` | до 1440 px |
| Планшет | `Portfolio Landing — Tablet / 768` | 768 px |
| Телефон | `Portfolio Landing — Phone / 390` | 390 px |

Секции и карточки в макете собраны на Auto Layout. Основной десктопный фрейм на момент передачи был вручную сужен до 1339 px, поэтому его название «/ 1440» следует воспринимать как максимальную ширину, а не как текущий размер. В коде адаптивность нужно закрепить медиазапросами: Figma не переключает десктопный фрейм в мобильный автоматически.

Рекомендуемые точки перехода:

- `> 1024px` — десктопная композиция;
- `768px–1024px` — планшетная композиция;
- `< 768px` — мобильная композиция;
- `< 480px` — компактный телефон.

Существующие левое и правое поля на широких экранах являются частью композиции. Их не нужно перераспределять в пользу контента.

## Внешний фон и контейнер

Страница всегда имеет фон на всю область окна браузера. Содержимое лендинга расположено внутри центрального контейнера с `max-width: 1440px`; его существующая сетка и положение элементов не меняются на широких экранах.

```css
:root {
  --color-bg: #f3f0ea;
  --color-ink: #1d1d1b;
  --color-accent: #b65c47;
  --color-light: #f7f5f0;
}

body {
  margin: 0;
  background: var(--color-bg);
  color: var(--color-ink);
}

.portfolio {
  width: min(100%, 1440px);
  min-height: 100vh;
  margin-inline: auto;
  background: var(--color-bg);
}
```

Не использовать `transform: scale()` и не увеличивать ширину внутренних колонок на мониторах шире 1440 px.

## Стиль

- Светлый тёплый фон, графитовый текст и терракотовый акцент.
- Шрифт: DM Sans.
- Много воздуха, крупные заголовки, аккуратная модульная сетка.
- Тёмные шапка, блок контактов и футер; текст в них светлый.

## Секции

1. Шапка: «Услуги», «Работы», «Обо мне», «Контакты».
2. Первый экран / представление.
3. Услуги.
4. Selected Projects: презентация, рабочие листы, карточки для социальных сетей.
5. Обо мне.
6. Контакты.
7. Футер.

## Поведение на узких экранах

- Колонки переходят в вертикальный порядок, без обрезания текста.
- Текстовые блоки сохраняют заданную максимальную ширину и переносят строки; не скрывать их за краем экрана.
- Карточки кейсов на телефоне располагаются одна под другой.
- Горизонтальное меню при необходимости заменяется на кнопку меню.
- Фотографии и миниатюры должны использовать `width: 100%`, `height: auto` внутри своих контейнеров.

## Проверка перед публикацией

- 1440, 1024, 768, 390 и 320 px: нет горизонтального скролла.
- Заголовки, описания и ссылки не обрезаются.
- Фон виден по бокам на широком экране, а элементы остаются на своих местах.
- Оверлеи кейсов прокручиваются полностью и закрываются по клику вне содержимого.
